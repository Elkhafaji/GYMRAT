====================================================
🏋️ GYMRAT — تشغيل المشروع في ٣ خطوات
====================================================

الخطوة ١ — ثبّت Node.js (لو مش عندك):
   نزّل النسخة LTS من: https://nodejs.org
   (للتأكد إنه اتثبت: افتح Terminal/Command Prompt واكتب: node -v
    لازم يطلع رقم v18 أو أعلى)

الخطوة ٢ — شغّل المشروع:
   افتح Terminal/Command Prompt جوّه مجلد المشروع (gymrat)
   واكتب الأمر ده:

        npm run dev

   هيفتح الموقع على:  http://localhost:5173
   والـ API شغّال على: http://localhost:4000

الخطوة ٣ — استمتع 🙂
   جرّب كوبون الخصم: GYMRAT10 أو GYMRAT15
   والشحن مجاني للطلبات فوق $50

====================================================
⚠️ لو ظهر أي خطأ أول تشغيل (غالبًا على Windows):
====================================================
الملف الكامل جاي بمكتبات Linux جاهزة. لو جهازك Windows
أو Mac، امسح مجلد node_modules واكتب:

        npm install
        npm run dev

(محتاج إنترنت مرة واحدة بس لتحميل المكتبات — حوالي ١٩٠ ميجا —
وبعدين يشتغل بدون إنترنت)

====================================================
أوامر تانية:
====================================================
   npm start      تشغيل نسخة الإنتاج (Build جاهز) على بورت 4000
   npm run build  إعادة بناء نسخة الإنتاج
   npm run db:seed إعادة زرع قاعدة البيانات (٣١ منتج + الفئات)
